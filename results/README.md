# Results

`results/engineer-b/` is generated by `scripts/run_b.py` only; never edit it by hand.

Reproduce (fresh clone, Python 3.12 via `uv`):

```bash
uv run --python 3.12 python scripts/run_b.py --seed 0 --controls
```

Tests: `uv run --python 3.12 pytest` (fast, 10 seeds) and `uv run --python 3.12 pytest -m slow` (counted, 50 seeds).

Files per session and method: `<session_id>__<method>.json` (`MethodResult`), `<session_id>__<method>__R.npz` (R(t) on PRE and POST NREM frames), `summary.csv`, and `controls.json` (matched positive and negative controls).
The `data` column of `summary.csv` says whether the run used real or synthetic sessions.

## Method IDs

Code and results use the team-brief IDs (`plans/engineer-b.md` section 0).

| Team brief ID (`research/team-brief.md` section 4) | Source-of-truth ID (`research/source-of-truth.md`) |
|---|---|
| M3 PCA reactivation strength | M4 (PCA per-component projectors), with M5 (number of significant components) |
| M4 ICA reactivation strength | M6 (ICA assembly patterns), with M5 |
| (not a team method) | M3 (projection onto the full correlation matrix) |

## Fields

- `score`: mean over significant components of (mean R in POST NREM - mean R in PRE NREM); > 0 is the "yes" direction.
- `p_n1`: one-sided p against N1 (per-neuron circular shift of PRE and POST, templates fixed from TASK).
- `details.p_blockswap`: one-sided p from permuting 20 s blocks of R(t) between PRE and POST; catches assemblies already present in PRE (plan Step 3 limitation).
- `details.n_sig`: TASK components above the N1 eigenvalue bound (95th percentile of the per-shuffle largest eigenvalue); `details.mp_bound` is the analytical bound, reported only.
